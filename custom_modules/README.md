# Custom Modules (Modules Personnalisés)

Ce dossier contient les modules développés en interne par SMSolution / IWA.

## Modules actuels

- **custom_partner** : Ajout du champ "Code Interne" et "Note Interne" sur la fiche partenaire.

## Convention de nommage

Préfixe recommandé : `sms_` ou `iwa_` pour identifier facilement les modules internes.
